Introduction to Cascading Style Sheets (CSS)

Cascading Style Sheets, commonly known as CSS, are used to format and design the layout of web pages. While HTML structures the actual content of a page, CSS controls the visual presentation (or appearance) such as colors, fonts, layouts, and spacing. When web designers want to make a site visually appealing and well-structured, CSS provides the tools to modify how HTML elements are rendered on a screen.

Standard 1: Three Ways to Apply CSS to a Website

Inline Styles

An inline style is used to apply a unique style directly to a single HTML element. Designers write the CSS code inside the HTML tag using the style attribute. Because inline styles only affect one specific element on a page, they are generally inefficient for styling an entire website, but they are useful for quick, single-element style adjustments.

Internal Stylesheets

An internal stylesheet is used to style a single web page by placing CSS rules directly inside the HTML document. These style rules are placed within the <style> tags located in the <head> section of the HTML file. While internal styles keep code organized for one individual page, they cannot easily share styling rules across multiple pages on a site.

External Stylesheets

Using an external stylesheet is considered the best coding practice for web development. In this method, all CSS rules are stored in a separate file with a .css file extension. This external file is then connected to HTML pages using the <link> tag in the head section, allowing a designer to change the look of an entire website by editing just one single file.

Standard 2: Essential CSS Syntax & Rules

Every CSS style rule consists of two main parts: a selector and a declaration block. The selector specifies which HTML element you want to style, such as a paragraph, heading, or image. Inside the curly braces, each declaration contains a property and a value separated by a colon (:). Every individual declaration must end with a semicolon (;) to separate it from the next rule. For example, in the rule p { color: blue; }, p is the selector, color is the property, and blue is the value.

/* Example Style Rule */ h1 { color: navy; text-align: center; }

Standard 2 (Continued): The CSS Box Model

In CSS, every HTML element on a webpage is treated as a rectangular box. The CSS Box Model describes how these layers are structured to calculate the total space an element takes up on the screen.

MARGIN (Outer transparent space)
BORDER (Visible/Invisible frame)
PADDING (Inner transparent space)
CONTENT (Text, Image, Video)

At the core of the box model is the content, which holds the actual text, image, or media. Directly surrounding the content is the padding, which creates transparent inner space around the content inside the box. Wrapping around the padding is the border, which forms a visible or invisible frame around the element. Finally, the margin creates transparent outer space beyond the border to push neighboring elements away.
